# Origin to Mouse Pointer

Set selected object origins to the 3D point under your mouse pointer.

**[Source code on GitHub](https://github.com/Unlim8ted-Studios/Origin-To-Mouse-Pointer-Blender-Addon)** ? [Report a bug](https://github.com/Unlim8ted-Studios/Origin-To-Mouse-Pointer-Blender-Addon/issues)

## Usage

In Object Mode, select the objects and invoke Origin to Mouse Pointer in the 3D Viewport. Shortcut settings are available in the add-on preferences. The default U shortcut is left disabled if another Object Mode action already uses it.

When the mouse is over geometry, the tool uses the surface hit point. In empty space, it uses a plane at the active object?s depth.
