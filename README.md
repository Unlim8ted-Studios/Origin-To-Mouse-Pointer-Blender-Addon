# Origin To Mouse Pointer (Blender Add-on)

![Downloads](https://shields.io)

---

## Overview
This add-on makes changing an objects origin in Blender quick and easy. Normally you would have to first change the world cursor, select an object, and then set its origin to the world cursor. With this add-on its as simple as moving your mouse, and then pressing a hotkey on your keyboard.

## Installation

1. Navigate to the releases tab:
   - Click on the latest release
   - Click the link titled **Origin-To-Mouse-Pointer.zip** to download the add-on.

2. Open Blender.

3. Go to:

   `Edit → Preferences → Add-ons`

4. Click **Install from Disk** and select the downloaded ZIP file.

5. Enable the add-on.

After installation, the hotkey can be configured in the add-on tab where it was enabled.

## Usage
Once enabled, simply select an object, move your cursor, and press the hotkey chosen (by default U if available). The selected objects origin will jump to your cursor with the same logic as the world cursor placement.
